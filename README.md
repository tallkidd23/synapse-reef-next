# Digital Paludarium

A minimal emergent life sim — plants, herbivores, evolution, and self-chronicling.

## Purpose

This is a free template for community education and experimentation. It is intentionally simple: no build step, no dependencies, just HTML, CSS, and JavaScript.

## How it works

- Plants grow, spread, and compete for space.
- Herbivores wander, graze, reproduce, and die.
- Traits shift over generations through simple mutation.
- The system records notable events in a living chronicle.

## Run locally

Open `index.html` in a browser. No server is required, though a local server is recommended for consistent behavior.
